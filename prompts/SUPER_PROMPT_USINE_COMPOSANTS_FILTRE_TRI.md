# SUPER PROMPT : L'USINE À COMPOSANTS EN TÂCHE DE FOND & LE FILTRE DE TRI IMPITOYABLE
================================================================================
NOM DU MODULE : BACKGROUND COMPONENT FACTORY & RUTHLESS SELECTION GATE (BCF-RSG)
SYSTÈME : Φ_SOI KERNEL / WINDOWS 11 IA ÉDITION / ATELIER STUDIO PRO
OBJECTIF : PRODUCTION AUTONOME NON-INTRUSIVE & PROMOTION SÉCURISÉE EN 1 CLIC (Ξ ≡ 1)
================================================================================

```markdown
Tu agis en tant que Directeur d'Usine Logicielle Autonome et Gardien du Filtre de Tri Impitoyable du Système Φ_SOI.
Ton mandat est d'implémenter l'infrastructure complète transformant la machine en une USINE À COMPOSANTS CONTINUE EN ARRIÈRE-PLAN couplée à un FILTRE DE SÉLECTION AUTOMATISÉ qui libère totalement l'utilisateur de la vérification manuelle du code.

L'utilisateur doit pouvoir utiliser son Bureau Windows 11 IA, coder ou converser avec ses agents en toute sérénité, pendant qu'en coulisse la machine invente, prototype, teste et certifie des briques logicielles prêtes à l'emploi.

Tu dois concevoir et implémenter de manière intégrale et modulaire les composants suivants :

--------------------------------------------------------------------------------
1. L'USINE À COMPOSANTS CONTINUE EN ARRIÈRE-PLAN (`BackgroundComponentFactory.ts`)
--------------------------------------------------------------------------------
- Fonctionnement asynchrone non-intrusif (Background Daemon à 0 % de latence sur l'UI principale).
- File d'attente d'inspiration et de besoins (Needs Queue) :
  * Convertisseurs d'unités de chantier (pieds carrés <-> m², verges cubes de gravier/terre, tonnes métriques, compactage).
  * Calculateurs géométriques spécialisés (polygones complexes Shoelace, pentes de drainage SO(2), profilage de fondations nordiques à 48 pouces de gel).
  * Widgets d'interface Windows 11 Fluent (mini-jauges de télémétrie VRAM GPU, horloges planétaires, cartes d'arpentage vectorielles, blocs-notes à chiffrage instantané).
  * Outils d'agents & connecteurs synaptiques (parsers de logs, formateurs de JSON stricts, extracteurs de métadonnées).
- Régulation automatique de la cadence :
  * L'usine surveille l'activité de l'utilisateur : elle suspend ses cycles lourds si l'utilisateur est en train de compiler du code ou d'exécuter une tâche critique, et reprend à plein régime dès que le système est en veille/idle.

--------------------------------------------------------------------------------
2. LE FILTRE DE TRI IMPITOYABLE AUTOMATISÉ (`RuthlessSelectionGate.ts`)
--------------------------------------------------------------------------------
- Zéro intervention humaine requise pour la vérification du code : l'utilisateur n'a pas à relire des milliers de lignes de TypeScript.
- Le Filtre élimine sans pitié 100 % des composants présentant la moindre anomalie :
  * Filtre 1 - Syntaxe & Typage Stricte : 0 avertissement TypeScript, interfaces déclarées, absence formelle de `any` ou d'appels non sécurisés.
  * Filtre 2 - Robustesse d'Exécution : Injection de cas limites (entrées nulles, `undefined`, nombres infinis, chaînes géantes). Si le composant lève une exception non gérée, il est immédiatement rejeté.
  * Filtre 3 - Isolation & Zéro Fuite : Vérification qu'aucune ressource externe payante n'est appelée en douce et qu'aucune variable globale n'est polluée.
  * Filtre 4 - Stabilité Déterministe >= 99 % : Le composant doit produire exactement le résultat attendu sur 5 passes consécutives.
- Tout composant recalé est instantanément recyclé en Erreur Fertile (σ_err) dans le registre d'apprentissage en arrière-plan sans jamais déranger l'utilisateur.

--------------------------------------------------------------------------------
3. LE REGISTRE DES ARCHIVES CERTIFIÉES & NOTIFICATIONS DISCRÈTES (`CertifiedArchiveStore.ts`)
--------------------------------------------------------------------------------
- Les composants ayant triomphé du Filtre Impitoyable sont scellés cryptographiquement en SHA-256 et catalogués dans l'Archive Certifiée :
  * `id` : Identifiant unique du composant.
  * `title` : Titre explicite (ex: "Calculateur de Pente et Déblai Nordique SO(2)").
  * `category` : `'converter' | 'geometry' | 'widget' | 'agent_tool' | 'visualizer'`.
  * `previewSnippet` : Aperçu direct du rendu visuel ou signature de la fonction mathématique.
  * `performanceScore` : Temps d'exécution moyen (ex: 0.12 ms), consommation mémoire (ex: 45 Ko).
  * `sha256Hash` : Empreinte immuable de l'ancrage matériel (Plan Delta).
- Notification discrète façon Windows 11 Action Center (son doux et toast discret dans le coin inférieur droit) :
  *"Nouvelle brique certifiée disponible : Widget Jauge Énergie Victron (Stabilité 100%, 0$ token)"*.

--------------------------------------------------------------------------------
4. LE PANNEAU DE PROMOTION EN PRODUCTION EN 1 CLIC (`OneClickPromotionCenter.tsx`)
--------------------------------------------------------------------------------
- Intégré dans l'Atelier Studio et accessible depuis le menu Démarrer Windows 11 IA.
- Interface élégante Fluent Design (Mica/Acrylic) affichant la galerie des créations certifiées prêtes à l'emploi :
  * Badges de catégorie, note de stabilité, aperçu du code et de l'interface en direct (Sandbox preview iframe ou composant dynamique).
  * Filtres par type d'outil (Calculateurs, Convertisseurs, Widgets, Outils IA).
  * LE BOUTON D'ACTION MAÎTRE : **[ Promouvoir en Production ]** (en surbrillance bleue cobalt).
- Au clic sur "Promouvoir en Production" :
  1. Le moteur vérifie l'absence de conflit de nom dans le dossier de destination (`src/components/` ou `src/services/`).
  2. Il écrit le fichier TypeScript propre et formatté directement dans l'arborescence du projet.
  3. Il met à jour les index d'exportation sans redémarrage nécessaire.
  4. Un message de confirmation vert s'affiche : *"Composant ancré avec succès dans le projet (Ξ = 1.000)"*.

--------------------------------------------------------------------------------
5. API BACKEND ET SURVEILLANCE SYSTÈME (`server.ts`)
--------------------------------------------------------------------------------
- Routes dédiées :
  * `GET /api/factory/status` : État de l'usine (En veille, En production, En phase de test).
  * `GET /api/factory/certified` : Liste des composants certifiés disponibles pour promotion.
  * `POST /api/factory/promote/:id` : Injection sécurisée du composant dans le code source de l'application.
  * `POST /api/factory/trigger` : Permet à l'utilisateur ou à un agent de suggérer une idée de composant à forger en tâche de fond.

Génère et assemble ce système en TypeScript strict, avec une ergonomie chirurgicale, pour que l'utilisateur dispose d'une forge logicielle autonome qui produit continuellement de la valeur sans jamais polluer sa concentration.
```
